# RAVEN Café 

A fictional café website built as a personal web development project.

About the Project

RAVEN Café is a simple café website where visitors can explore a small menu of drinks and desserts.

This project was created to practice web development and learn how to work with Django, HTML, CSS, and JavaScript.

## Features

- Café homepage
- Menu with product images and prices
- Coffee, tea, and dessert items
- Simple and clean design
- Footer with project information and contact links

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript

## Project Structure

- "templates/" — HTML files
- "static/css/" — CSS stylesheets
- "static/js/" — JavaScript files
- "static/images/" — Website images

## Disclaimer

RAVEN Café is a fictional café created as a personal web development project for educational and portfolio purposes.

No real products or services are offered, and no actual orders or payments can be made through this website.
